# Anthony_portfoilio

Single-page responsive Next.js portfolio.

## Project interaction
Anthony now uses the horizontal project-viewer concept:
- current project dominates the center
- previous and next projects stay visible at the sides
- side previews show label, project name and short context
- mouse wheel / trackpad, drag/swipe, keyboard arrows and clicking side cards all work
- Personal and University categories can contain any number of projects
- categories with only one project automatically remove Previous/Next controls

## Run
```bash
npm install
npm run dev
```
